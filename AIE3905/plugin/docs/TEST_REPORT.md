## 关键覆盖

- 提议与确认区分、引用“可以”的依赖传播、无权限取消保持待确认。
- 负责人确认取消后，正式状态为取消，而不是误写回“已确认”。
- 改期后的当前结论、历史原因、同一成员的简短追问。
- 系列安排与单次改动、个人缺席与活动取消区分。
- 更正保留未变字段及其证据，优先级可以调低。
- 撤回新安排后不自动恢复旧安排；独立确认可继续有效。
- 编辑修订、重复消息、重启恢复、有限重试和处理状态可见。
- 跨群访问与证据拒绝；回放不使用未来消息。
- 退出记录、删除后不能重放恢复、过期原文清理。
- 长期原文全文检索、删除时同步清理全文索引。
- 模型选出不存在的事实条目时回退，生成期间删除证据时丢弃旧快照。
- 冲突提醒冷却、模型与提示版本跟踪。
- 管理页面无令牌拒绝，远端模型需要明确配置与 HTTPS。
