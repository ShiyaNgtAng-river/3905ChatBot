# 多模态接入验证记录（2026-10-02）

## 已实测

环境：当前 Mac，Python 3.12.14，macOS Vision；faster-whisper 1.2.1 / CTranslate2 4.8.2 / PyAV 18.1.0，base 模型 CPU int8。依赖见 requirements.lock.txt。

| 项目 | 方法 | 结果 |
|---|---|---|
| OCR | 程序绘制的中文会议通知，1400×620 | 五行内容与样本一致；日期、15:30、B302、“尚未确认”四项检查全通过 |
| ASR | 系统 Tingting 合成的约 9.8 秒普通话录音 | 日期、时间、302会议室、未确认均保留；开头“这是测试录音”误识别为“這事測實錄音”，并有繁体字 |
| 静音 | 5 秒全零 WAV | 返回空文本，无编造文字 |
| 文本模型工具调用 | 已配置的 deepseek-flash，自主选择所提供的媒体工具，工具经插件 → HTTP → 本地识别 | OCR、ASR 两条链路均得到正确要点回答，均表述尚未确认 |
| 缺少生图账号 | 调用生图工具 | 返回未配置，没有生成或发送图片 |

该次本机 HTTP 请求计时：OCR **351 ms**，ASR **1235 ms**，静音 **466 ms**。这是单样本功能检查，包含本次服务处理过程，不是冷启动、并发、端到端 QQ 延迟或准确率基准。

真实 DeepSeek 共 **4 次模型调用**（两次选择工具、两次根据工具结果回答），总计 **1953 token**（输入 1692，输出 261，输入中命中缓存 512）。仅使用虚构资料；图片和音频留在本机，云端只收到了测试提示与识别文字。没有进行实际云端视觉识别或生图。

本地语音权重来源：`Systran/faster-whisper-base`，revision `ebe41f70d5b6dfa9166e2c581c45c9c0cfc57b66`。完整文件 SHA256 记录在私有运行目录的 model-manifest.json。

## 尚未得出的结论

这些样本不能证明真实嘈杂群聊的识别准确率。尚未测试多人录音、口音、QQ SILK 转码、低清截图、真实引用附件投递、并发压力以及当前线上人格的工具选择。OCR 不具备完整场景理解；媒体也尚未接入自动长期记忆。正式云端视觉/生图需要账号后单独验证，不应把模拟响应测试称为模型实测。

私有原始证据在项目 `.sandbox/multimodal-20261002/` 的 smoke-results.json、ocr.json、transcribe.json、silence-result.json；它们不进入交付 ZIP。线上配置、凭据、真实群聊和模型权重也不打包。
